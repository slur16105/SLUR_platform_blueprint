## 세 시안이 공유하는 것

콘텐츠·문구·상품 데이터는 **완전히 동일**하다 (`.working/CONTENT-BRIEF.md`).
비교 대상은 오직 **톤**이다. 세 시안 모두 다음 요구사항을 실제로 그렸다:

| 요구 | 어디에 |
|---|---|
| FR-10 품절을 숨기지 않고 표기 | 상품목록의 `황동 촛대 세트` |
| FR-9·10 2축 옵션 조합 + 품절 조합 비활성 | 상품상세의 `먹 / 320ml` |
| FR-32 청약 전 판매자 신원정보 + 중개자 고지 | 상품상세 하단 |
| FR-15 판매자별 묶음 (배송비가 판매자 단위) | 장바구니 3묶음 |
| FR-35 담은 뒤 품절된 항목의 "구매 불가" 처리 | 장바구니의 `곳간` 묶음 |
| 금액 정합 | 118,000 + 3,000 = **121,000원**, `주문하기 (2건)` |

v1에 없는 것(검색·리뷰·별점·찜·쿠폰·알림)은 **의도적으로 그리지 않았다.**

## A · 갤러리

`.working/direction-a-gallery.html` · `direction-a-gallery.png`

상품을 진열하지 않고 **작품처럼 놓는다.** 1열 대형 이미지, 과장된 여백, 헤어라인만으로 구획.
제목·브랜드는 명조(AppleMyungjo), 본문·숫자는 고딕. 브랜드 파랑을 쓰지 않는다.

- **강점** — 큐레이션 편집숍이라는 정체성이 가장 또렷하다. 상품 하나하나가 존중받는 인상. 판매자에게 "여기 들어오면 내 물건이 이렇게 보인다"고 설득하기 좋다.
- **약점 (시안에 그대로 드러남)** — 가격이 12px 회색이라 이미지에 묻힌다. `장바구니 담기`가 옅은 선 버튼이라 `바로 구매`보다도 약하다. 하단 탭이 없어 화면 이동이 상단 헤더에만 의존한다. **상품 6개를 보는 데 스크롤이 약 3,000px** — 상품이 30개가 되면 탐색이 무너진다.
- **판단 지점** — 초기 상품 수가 적을 때(판매자 5~10팀) 가장 아름답고, 상품이 늘수록 가장 먼저 한계가 온다.

## B · 매거진

`.working/direction-b-editorial.html` · `direction-b-editorial.png`

**큐레이션이 눈에 보이는** 톤. 종이 같은 오프화이트(`#faf8f4`)에 먹색(`#1f1d1a`), 흙빛 액센트(`#8c4a32`) 소량.
브랜드명이 상품명보다 먼저·강하게 읽힌다(11px / 800 / 자간 .15em). 2열 비균일 그리드로 지면의 리듬을 만든다.

- **강점** — 편집숍의 결과 탐색 가능성 사이의 절충. "누가 골랐는가 / 어느 브랜드인가"가 먼저 읽혀 큐레이션 서사가 산다. A보다 3배 가까이 많은 상품이 한 화면에 들어온다.
- **약점 (시안에 그대로 드러남)** — 목록 프레임에 `첫 화면 끝 · 844px` 점선을 그어 놓았다. 첫 화면에 상품 4개 남짓이 들어온다 — C보다 성기고 A보다 촘촘한 중간 밀도다.
- **판단 지점** — 상품상세에 옵션 칩 행과 조합 목록이 **둘 다** 그려져 있다. 정적 목업이라 품절 조합을 보여주려고 이중으로 표현한 것이며, 실제 구현에서는 한 벌로 합쳐야 한다.

## C · 상점

`.working/direction-c-shop.html` · `direction-c-shop.png`

익숙한 커머스 문법으로 **또렷하게 판다.** 기존 슬러 시스템을 그대로 모바일로 확장하고,
브랜드 파랑 `#2f6bff`를 선택·CTA·활성 탭에 실제로 쓴다. 2열 균일 그리드, 배지, 하단 탭 내비 4개, 고정 구매 바.

- **강점** — 처음 온 사람이 헤매지 않는다. 상태(품절·무료배송·구매 불가)가 배지로 한눈에 읽히고, `결제 예정 금액 121,000원`이 가장 크게 잡힌다. 전환에 가장 유리하고, **구현이 가장 빠르다** — 판매자·관리자 화면과 컴포넌트를 그대로 공유한다.
- **약점 (시안에 그대로 드러남)** — 큐레이션 편집숍의 특별함이 거의 사라진다. 여느 쇼핑몰 화면과 구분되지 않는다.
- **판단 지점** — **이 시안만 브랜드 파랑을 쓴다.** 따뜻한 색의 상품 사진 위에 차가운 파랑이 얹히는 인상이 실제로 어떤지가 이 선택의 핵심이다.

## 결정해야 할 것

### 1. 톤 (필수)

| | 편집숍다움 | 탐색 효율 | 전환력 | 구현 속도 |
|---|---|---|---|---|
| A 갤러리 | ●●● | ● | ● | ●● |
| B 매거진 | ●● | ●● | ●● | ●● |
| C 상점 | ● | ●●● | ●●● | ●●● |

**세 안을 섞는 선택도 가능하다.** 예: B의 지면 톤 + C의 하단 탭 내비·고정 구매 바.
가장 흔한 실패는 A를 고른 뒤 상품이 늘어 결국 C로 되돌아가는 것이다.

### 2. 브랜드 파랑 (필수)

`#2f6bff`를 구매자 화면에 쓸 것인가. 판매자·관리자 화면에는 이미 쓰이고 있어,
쓰지 않기로 하면 **한 앱 안에서 역할별로 색이 갈린다** (문제는 아니지만 의도된 결정이어야 한다).

### 3. 하단 탭 내비게이션 (필수)

C에만 있다. 있으면 이동이 쉽고 앱 같은 인상이 강해지지만, 화면 아래 56px을 상시 점유한다.
PWA 설치 후 홈 화면에서 실행되는 경험을 고려하면 있는 쪽이 자연스럽다.

### 4. 미결 — 선택 후 정해도 되는 것

- 구매자 홈 라우트를 `/`로 둘지 `/shop`으로 둘지 (현재 `/`는 로그인 유도 랜딩)
- 상품상세 옵션 UI를 축 선택형으로 할지 조합 목록형으로 할지 — 세 시안이 각각 다르게 풀었다
- Pretendard 폰트: 시안은 로컬 Apple SD Gothic Neo 폴백으로 렌더됐다. 실제 서비스는 Pretendard를 쓰므로 자간·굵기 인상이 조금 달라진다

## 알려진 한계 (세 시안 공통)

- **정지 화면이다.** JS 금지 제약으로 카테고리 가로 스크롤, 판매자 정보 접힘, 조합 선택 갱신은 정지 상태로만 표현했다.
- **이미지는 CSS 도형이다.** 실제 상품 사진이 들어오면 인상이 달라진다 — 특히 A는 사진 품질에 가장 크게 의존한다.
- 프레임 안 스크롤이 없어 헤더 고정 여부는 표현되지 않았다.
