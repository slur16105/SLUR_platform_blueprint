**기준선(baseline)** — [.working/home-c-feature.html](./home-c-feature.html) + [home-shared.css](./home-shared.css). 이 문서는 그 목업을 dev가 그대로 옮길 수 있는 스펙으로 정리하고, **참고 스크린샷([imports/pc.jpg](../imports/pc.jpg), EQL PC 홈) 관찰로 보강한 차이만** §7에 명시한다.

## 1. 절대 규칙 (어떤 섹션에도 예외 없음)

1. **이미지 위에 텍스트/오버레이 그라디언트 금지.** 표제·눈썹·서문·CTA·라벨은 항상 이미지 **아래(또는 옆) 블록**에 둔다. 참고 EQL은 히어로·타일·배너에 텍스트를 얹지만 우리는 전부 이미지 아래로 내린다.
2. **색·활자·간격은 `--b-*` 토큰에서만.** 브랜드 파랑 없음. 유채색은 액센트 벽돌빛 `--b-accent`(#8c4a32) 하나이며 링크·`이번 지면` 눈썹에만.
3. **깊이 장치 3종뿐** — 8px 종이 접기 띠(`--b-band`) · 1px hairline · 테두리 상자. `box-shadow` 0.
4. **v1 밖 기능 0** — 검색·리뷰·별점·찜·쿠폰·알림·캐러셀·타이머·할인율·배너 세일을 어디에도 그리지 않는다(EQL 상단 검색·쿠폰 배너·`-50%` 배너·회원 혜택 배너 전부 무시).
5. 외부 리소스·JavaScript 최소. 애니메이션·자동재생·스크롤 하이재킹 없음(EXPERIENCE §Interaction Primitives).

## 5. 편성 데이터 → 섹션 매핑

편성(지면/`feature`) 1건이 홈 한 판을 채운다. 개념 모델(관리자 편성 화면·테이블은 Dan 승인 후 확정):

```
feature (지면)
  hero            → §3.2 히어로 : image_url · eyebrow("이번 지면") · issue_no("NO. 07 · 2026.07")
                                 · title(2줄) · lede(서문) · cta_href("지면 보기")
  slots[] (N개, 노출 순서)
    type = "split" → §3.3 편성 슬롯1 : kicker·title·prose·more_href + picks[2] (product refs)
    type = "strip" → §3.4 가로 스트립 : label·prose + picks[N] (product refs)
  (품목은 product ref만 저장 — 브랜드·이름·가격·이미지·sold_out은 상품 API에서 조인)
```

- 슬롯 `picks[]`는 상품 참조이므로 **가격·품절 상태는 실시간 상품 데이터를 따른다** — 편성에 박제하지 않는다. 편성 상품이 품절되면 카드가 `sold_out` 규칙을 상속(§3.6, EXPERIENCE §편성 지면).
- 카테고리 칩·전체 상품 그리드(§3.5·3.6)는 편성과 **무관**하게 기존 상품 조회를 그대로 쓴다 — 편성 위/아래에 항상 선다.

## 6. 빈 상태 · 폴백 · 스크롤 복원 (EXPERIENCE §State Patterns 편성 지면)

| 조건 | 동작 |
|---|---|
| 활성 히어로 없음 | 히어로를 그리지 않고 **서문형(A안)으로 폴백** — 큐레이션 서문(활자·여백만) + 카테고리 칩 + 전체 상품 그리드. 낡은/빈 히어로를 남기지 않는다. |
| 편성 슬롯 품목 0 | 그 슬롯을 **접는다**(빈 자리 없음). 슬롯 전부 비면 히어로 아래 바로 칩·그리드. |
| 편성 상품 품절 | **숨기지 않고** `sold_out` 규칙 상속(채도↓ + `품절` 태그 + 가격 취소선). |
| 편성·상품 모두 0 | 상품 목록 빈 상태 `이 카테고리에는 아직 상품이 없습니다.` |
| 로딩 | 카드 골격(skeleton). 중앙 스피너 금지. |

**스크롤 복원 (Q4)** — 홈이 2~4배 길어지므로 **상품상세 → 뒤로 시 홈 스크롤 위치를 복원**한다(맨 위로 튀지 않음). 브라우저 기본 스크롤 복원(뒤로/앞으로에서 복원, `history.scrollRestoration`을 `manual`로 덮지 않음)에 맡기며, SPA 라우팅이 홈 복귀 시 스크롤을 0으로 리셋하지 않도록 홈 라우트가 복원을 보장한다. 같은 탭 재탭은 최상단 복귀(기존 규칙 유지).

## 7. 기준선(home-c-feature.html) 대비 — 스크린샷 관찰 보강 차이

기준선 목업은 이미 C의 골격(전면 히어로 → 편성 슬롯1 5:7 → 가로 스트립 → 카테고리 칩 → 전체 그리드 → 푸터)을 담고 있다. 스크린샷 관찰로 **명시적으로 보강/재확인**한 점:

1. **에디토리얼 캡션은 이미지 아래** — EQL이 실제로 이 형태(4열 카드 캡션 하단)를 쓴다는 것을 확인. 우리 "텍스트 이미지 아래" 규칙이 참고 대상과 충돌하지 않음을 재확인했다(오버레이는 히어로·배너에만 있었고 그건 기각).
2. **히어로는 단일 전면 이미지 유지** — EQL의 이미지+타일 분할 히어로는 오버레이 의존이라 기각. 기준선의 전면 단일 이미지 + 아래 블록이 옳다. 변경 없음.
3. **섹션 수직 리듬을 크게** — EQL의 넉넉한 섹션 간격을 확인. 기준선의 8px 접기 띠 + 섹션 padding(§3)이 이 리듬을 구현. **칩–그리드 사이 이중선 금지**를 스펙에 명문화(기준선 CSS에 이미 반영, 스펙에서 규칙으로 승격).
4. **가로 스트립은 참고 대상에도 존재** — EQL 상품 스트립이 우리 `b_strip`과 같은 문법임을 확인. scroll-snap 금지는 우리 렌더 검증 결함이지 EQL 관찰이 아니다(그대로 유지).
5. **기각을 명시** — EQL의 카테고리 이미지 타일·전면 세일 배너·캐러셀 화살표·쿠폰/회원 혜택 배너·브랜드 4열 그리드는 전부 채택하지 않음(§2). 특히 브랜드 그리드는 시안 B의 IA이며 C의 얼굴이 아니다.

**결론** — 기준선 목업을 구조 변경 없이 그대로 옮긴다. 스크린샷은 새 구성 요소를 더하지 않고, 기존 C의 판단(전면 히어로 + 텍스트 하단 + 편성 슬롯 + 스트립 + 리듬 그리드)을 확증하며 기각 목록을 분명히 하는 역할이었다.
