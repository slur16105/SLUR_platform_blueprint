# PRD 부록 — 다운스트림 문서용 깊이 자료

PRD 본문에 넣지 않기로 한 근거·기술 결정·기각 대안. 아키텍처/ERD/UX 설계 시 참조.

## 기각된 대안과 이유

| 대안 | 결정 | 이유 |
|---|---|---|
| 판매자별 분리 장바구니 | 기각 | Slur가 타 사이트에서 직접 겪고 이탈한 UX. 무신사·네이버처럼 구매자에겐 단일 장바구니, 내부는 판매자별 하위 주문으로 분리 |
| 배송비 전면 무료(플랫폼 강제) | 기각 | 무료배송 비용은 판매자 부담이 되어 입점 협상 카드를 시스템이 선점하는 꼴. 판매자 설정으로 전환 |
| SLUR의 배송비 부담/정산 시 지원 | 보류(PG 시점 재논의) | v1에 정산 시스템이 없음. 한 번 시작한 무료는 회수 불가. 수수료 없이 배송비만 부담하면 주문 증가 = 적자 증가 구조 |
| 네이버·구글 로그인 | 보류 | 카카오가 국내 소셜 로그인의 60~70%를 차지해 대다수 커버. 제공자 추가 시 중복 계정 문제(동일인이 다른 제공자로 가입) 발생. OAuth 구조를 범용으로 만들어 추후 며칠 수준의 작업으로 추가 가능하게 함 |
| iOS 동시 출시 | 보류 | iOS에 소셜 로그인을 넣으면 Apple 로그인 의무 발생(App Store 규정). Android 먼저, iOS는 Apple 로그인+심사 대응과 한 묶음으로 이후 진행 |
| 상품 검수(등록 승인) 단계 | 기각 | 초청제가 이미 품질 게이트. 소규모에서 운영 부담 대비 효익 없음 |
| 장바구니 담기 시점 재고 차감 | 기각 | 재고 잠김 문제로 업계 비표준. 주문 생성 시점 원자적 차감이 소규모 표준 |
| Supabase 풀스택 패턴 (클라이언트가 Supabase 직접 호출, Auth·RLS·Edge Functions 사용) | 기각 (브리프 시점 결정) | 권한·비즈니스 로직이 클라이언트·RLS·백엔드에 분산되는 것을 배제하고 FastAPI 단일 소유로 통일. 블루프린트 추출(2차 목표) 관점에서도 로직이 한 곳에 있어야 추출이 쉬움 |

## 기술·구현 노트 (아키텍처 문서로 갈 것)

- **재고 차감**: 주문 생성 시 조건부 UPDATE(수량 >= 주문수량일 때만 차감)로 음수 방지. soft reservation(체크아웃 타이머)은 대형 플랫폼 패턴으로 v1 불필요.
- **소셜 인증 구조**: 카카오 OAuth → FastAPI가 검증 후 자체 JWT 발급. provider 테이블/컬럼을 범용으로 두어 네이버·구글 추가가 스키마 변경 없이 가능하게 함.
- **옵션 데이터 모델 레퍼런스**: Shopify Product→Options(축)→Variants, Medusa ProductVariant(manage_inventory), Saleor Stock(quantity_allocated 예약분 분리 — 정산·클레임 도입 시 참고). 네이버 커머스API `optionCombinations[]` 구조가 조합형 표의 데이터 모델과 그대로 일치.
- **도서산간 판정**: 배송지 우편번호 → 도서산간 여부. 우체국/택배사 공개 우편번호 목록 기반 판정 테이블.
- **지급대행 규제 (PG 시점 필독)**: 구매자 돈이 플랫폼 계좌를 경유해 판매자에게 가는 구조는 전자지급결제대행업 등록 대상(전자금융거래법). PG의 지급대행/파트너정산 상품(토스페이먼츠 지급대행, 포트원 파트너정산 — 월 고정료 있음)으로 해결. `research-pg.md` 참조.
- **에스크로 의무 (실구매자 무통장 수령 시)**: 현금 결제 5만원 이상엔 구매안전서비스 의무. v1은 내부 테스트만이라 비적용이지만, "PG 전에 외부 판매를 시작하자"는 유혹이 생기면 이 의무가 되살아난다.

## 벤치마킹 수치 (사업 판단용)

- 판매수수료 구간: 네이버 5~6% / 쿠팡 10~11% / 오늘의집 12~25% / 아이디어스 ≤15% / 29CM 26~28% / 무신사 ~30%. 큐레이션 프리미엄의 현실 범위는 15~28%.
- 배송비를 상시 부담하는 플랫폼은 없음 — 기간 한정 프로모션 또는 구매자 유료 멤버십 형태만 존재.
- PG 초기비용(2026): 토스 가입비 22만원+연회비 11만원(무료 이벤트 종료), 나이스 조건부 무료, 포트원 경유 시 면제 경로. 상세 `research-pg.md`.
- 초청·승인제+독점 상품 전략 선례: 29CM 단독/선런칭, 컬리 큐레이티드 마켓플레이스, Trouva(규모화 실패 사례), Bespoke Post. 상세 `research-market.md`.
