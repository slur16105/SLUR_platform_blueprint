## A. 콘솔 회귀 — 가장 중요 (구매자 화면을 만들며 콘솔을 안 깨뜨렸는가)

관리자·판매자로 로그인해 기존 8화면을 둘러본다. 회귀가 제일 위험한 곳이다.

- [ ] **관리자 로그인** → 대시보드 진입. 레이아웃·숫자 정상
- [ ] 관리자: 입점 승인 / 회원·판매자·상품·주문 조회 / 입금 확인 화면 각각 열림, 표·필터 동작
- [ ] **판매자 로그인** → 판매자 대시보드, 상품관리, 주문관리 열림
- [ ] 판매자 상품 등록/수정 폼 정상(이미지 업로드 presign 포함)
- [ ] **포커스 링이 파랑**인지 — 콘솔 화면에서 Tab 키로 이동, 파란 포커스 링 유지(구매자 먹색이 새지 않았는지)
- [ ] 콘솔 어느 화면도 구매자 종이톤/하단 탭바가 새어 들어오지 않음
- [ ] (리뷰 회귀 재확인) 콘솔 상태변경 버튼(입금확인·주문상태·입점승인 등) 실제 눌러 서버 반영까지 1회씩

## B. 구매자 핵심 플로우

- [ ] 구매자 회원가입 → 필수 약관 동의 없으면 진행 불가, 동의 후 가입
- [ ] 로그인/로그아웃. 로그아웃 후 장바구니 배지 0으로 비워짐
- [ ] **담기 → 주문서 → 주문 → 취소** 각 1회 (프로덕션/프록시 뒤에서 상태 변경이 되는지 — 회고 R3)
- [ ] 주문서에서 **중개자 고지가 `주문하기` 버튼보다 위**에 있는지 (FR-32 규제 요건, ≥768 포함)
- [ ] 주문완료 화면에 주문번호 표시, 새로고침·뒤로가기에도 유지
- [ ] 주문내역·주문상세 열림, 취소된 묶음 배송비 취소선 처리
- [ ] **창 폭을 좁혔다 넓혔다** — 입력·선택·스크롤 위치가 초기화되지 않는지
- [ ] (리뷰 회귀) 스크롤 시 상단바 sticky 유지, 서울 전화번호 `02-1234-5678` 정상 표기

## C. Epic 9 — 구매자 홈 편성

- [ ] **관리자 → 홈 편성 관리(`/admin/home`)** 진입 (네비에 "홈 편성" 있음)
- [ ] 편성 목록에 히어로 1 + 슬롯 2 보임, 상품수·노출기간·순서·활성 표시
- [ ] **새 편성 생성** — kind(hero/slot)·layout·제목·문장·이미지경로·노출기간·상품 묶음 선택 후 저장
- [ ] 상품 묶음 선택기: 카테고리 필터 목록이 **비어 있지 않은지**(회귀 확인), 상품 담고 순서 ↑↓
- [ ] 없는/중복 상품, 종료<시작 기간 → 저장 시 오류 메시지 표시
- [ ] ↑↓ 순서 변경이 실제로 반영(무반응 아님), 활성 토글 즉시 반영
- [ ] **구매자 홈(`/`)** — 전면 히어로("이번 지면 · NO.01" + 이미지) → 편성 슬롯(비대칭 5:7) → 가로 스트립 → 카테고리칩 → 상품그리드 → 푸터 순
- [ ] 텍스트가 **이미지 위에 얹히지 않음**(표제는 이미지 아래 블록), 오버레이 없음
- [ ] **폴백** — 관리자에서 히어로를 비활성화 → 홈이 서문형("골라온 것들을…") + 상품목록으로 강등되는지
- [ ] 편성 상품에 품절 포함 시 숨기지 않고 sold_out(채도↓·취소선) 표기
- [ ] **스크롤 복원(Q4)** — 홈에서 스크롤 내려 상품 클릭 → 상세 → 뒤로 → **홈이 그 위치로 복원**. 반면 하단 홈 탭 재탭은 **최상단**
- [ ] **푸터(Q3)** — 홈뿐 아니라 상품상세·장바구니·주문서 등 전 구매자 화면 하단에 푸터가 있고, **고정 CTA 바가 푸터의 회사정보·중개자 고지를 가리지 않는지**(Epic 9 리뷰 H1 수정 확인)
